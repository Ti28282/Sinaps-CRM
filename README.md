# SINAPS CRM

Десктоп-CRM: чаты из папки Telegram попадают в воронку, база хранится в одном файле SQLite на компьютере.

**Стек:** Go 1.24 + Wails v2 (окно) · React 18 + Vite (статика вшита в бинарник) · SQLite через `modernc.org/sqlite` (чистый Go, без CGO) · Telegram через `gotd/td` (MTProto).

## Сборка

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@v2.10.1
go mod tidy
wails build              # → build/bin/SINAPS-CRM.exe
wails dev                # разработка с hot reload
```

Только фронт в браузере, с демо-данными и без Go:

```bash
cd frontend && npm i && npm run dev
```

Нужны Go 1.26+ (whatsmeow; при `GOTOOLCHAIN=auto` Go скачает его сам) и Node 20+. На Windows 10/11 WebView2 уже стоит.

**Иконка в доке Ubuntu:** после `wails build` один раз выполните `bash build/linux/install.sh`. Ярлык появится в меню приложений, его можно закрепить в доке. Иконка лежит в `build/appicon.png`, из неё же Wails делает `.ico` для Windows.

## Первый запуск

1. Получите **API ID / API Hash** на my.telegram.org → API development tools.
2. Откройте «Подключения», введите ключи, номер, код и пароль 2FA, если он включён.
3. Выберите папку (по умолчанию ищется «clients») и нажмите «Импортировать».

Данные лежат в `%AppData%\SINAPS-CRM\` на Windows и `~/.config/SINAPS-CRM/` на Linux: `crm.db`, `tg-session.json`, `config.json` (тема и плагины) и папка `plugins/`. Файл сессии = доступ к аккаунту, не передавайте его никому.

## Почему нет дублей

| Таблица | Уникальный ключ | При повторном импорте |
|---|---|---|
| `chats` | `(channel, ext_id)`, где `ext_id` = `u123` / `c45` / `ch678` | обновляются имя и username; этап, сумма, заметка и теги **не трогаются** |
| `messages` | `(chat_id, msg_id)` | `ON CONFLICT DO NOTHING`, докачиваются только новые |

`channel` = `tg` или `wa`, так что WhatsApp встанет в ту же схему.

## Что умеет

- Импорт папки и последних N сообщений (по умолчанию 200) с обработкой FLOOD_WAIT.
- Живые сообщения (события Wails `message:new` и `chats:changed`), счётчик непрочитанных.
- Канбан с drag-and-drop: Новые → Написал → Ответил → Сделка → Потерян.
- Автоматическая смена этапа: ответ из CRM переводит «Новые» в «Написал», ответ клиента переводит «Написал» в «Ответил».
- Карточка клиента: сумма, следующий шаг, теги, заметка, история.
- Фото в переписке: качаются из Telegram при первом показе и кешируются в `media/` рядом с базой; клик — на весь экран.
- Отправка файлов и фото: скрепка или перетаскивание в окно диалога, подпись, до 1,5 ГБ. Фото по умолчанию со сжатием (галочка «Без сжатия» — файлом). Входящие файлы — карточкой, по клику скачиваются в `media/` и открываются.
- Удаления синхронизируются: удалил своё сообщение в Telegram — оно пропадает из CRM; клиент удалил своё — в CRM остаётся с пометкой «удалено клиентом».
- Удаление любого сообщения из CRM (значок корзины при наведении): «Только в CRM» — в мессенджере остаётся, синхронизация не вернёт; «У обоих» — Telegram в личке удаляет и своё, и сообщение клиента (в группах чужие — только админ), WhatsApp — только свои.
- Узкое окно: до 1280 px меню сворачивается в иконки, карточка клиента открывается кнопкой «Карточка» поверх переписки; до 900 px на экране либо список диалогов, либо переписка (кнопка «←»).
- Кнопка «↓» в переписке: появляется, когда прокрутил вверх, показывает число новых сообщений и одним нажатием возвращает в самый низ.
- Экспорт и импорт (Настройки → Данные): Excel (клиенты + вся переписка), CSV (клиенты; `;` и UTF-8 с BOM для русского Excel), полная копия базы `.db`. Импорт CSV/XLSX с предпросмотром: совпадения по ID канала, телефону, @username или названию обновляются, остальные добавляются лидами «Из файла»; понимает CSV в Windows-1251. Импорт `.db` заменяет базу, текущая сохраняется как `crm.db.bak-<дата>`.
- WhatsApp (whatsmeow, связанное устройство): вход по QR, чаты выбираются вручную из списка, история, присланная телефоном, подтягивается при выборе; живые сообщения, фото и файлы, удаление своих «у всех», удаления клиента остаются с пометкой. «Прочитано» не ставится, рассылок через WhatsApp нет. Сессия — `wa-session.db` рядом с базой.
- Рассылки по шаблону (`{name}`, `{title}`, `{username}`): лимит в день (по умолчанию 20), паузы 40–90 с, остановка при `PEER_FLOOD`.

Папка разбирается так же, как в Telegram: вручную добавленные чаты + правила («Контакты», «Группы», «Боты»…) минус исключения и «Без звука/Прочитанные/Архив».

## Плагины (0.2)

Плагин — архив `.sinaps` (zip) в папке `plugins/` рядом с базой (папку можно сменить в «Настройки → Плагины»):

```
manifest.json   {"id","name","version","description","requires":[…],"crm":">=0.2","icon"}
settings.json   {"fields":[{"key","label","type":"select|bool|text|number","options","default"}]}
icon.svg        необязательно
plugin.wasm     свой код — заработает в следующих версиях
```

Смотрятся только файлы `.sinaps`, остальное в папке не показывается. Статусы: **Подключён**, **Выключен**, **Ждёт** (нужен другой плагин), **Ошибка** (старая CRM, дубль id, неизвестный плагин), **Не плагин** (нет `manifest.json`, битый архив). Вкл/выкл и настройки — в `config.json`, архив не меняется. Удалили файл — плагин пропал, его данные в базе остались. Архив можно перетащить в окно «Плагины».

Раздел «Плагины» в меню слева появляется, только когда включён хотя бы один плагин со своей страницей.

**«Чеки» (`cheki.sinaps`)** — встроен в CRM и включается архивом. Страница «Чеки» сверху вниз: **новый чек** (клиент из воронки с поиском, сумма, за что, дата оплаты, статус: оплачен / ожидает / возврат) → **статистика** (получено, количество, средний чек, ожидают оплаты, диаграмма за 12 месяцев, топ клиентов, фильтр по клиенту и периоду) → **история** (все чеки, правка и удаление, 7 строк, дальше прокрутка). Экспорт в Excel. Чеки клиента видны в его карточке в «Диалогах». Настройки: валюта, «сумма чеков → сумма сделки», «первый оплаченный чек → Сделка». Чеки хранятся в таблице `receipts` и не пропадают, если клиента убрали из CRM. Ничего не отправляет клиентам.

Убрать чаты из CRM: кнопка рядом с папкой в «Подключениях» или корзина в диалоге. Чат удаляется только из CRM и попадает в список скрытых, синхронизация его больше не подтягивает. **Папки и чаты в Telegram приложение не меняет.** Вернуть скрытые можно в том же окне.

## Структура

```
main.go                     Wails: окно, embed frontend/dist
app.go                      методы для фронта + рассылки
internal/store/             SQLite: схема, upsert, тест на дубли
internal/telegram/          вход, папки, история, обновления, отправка
internal/whatsapp/          WhatsApp: QR, выбор чатов, история, сообщения, файлы
internal/dataio/            экспорт/импорт CSV, XLSX, SQLite
internal/config/            config.json: тема, плагины, папка плагинов
internal/plugins/           чтение папки .sinaps, статусы, зависимости
app_plugins.go              «Настройки → Плагины»: список, вкл/выкл, настройки, установка
app_receipts.go             плагин «Чеки»: отметки, отчёт, экспорт
frontend/src/api.js         мост window.go.main.App + демо-режим (mock.js)
frontend/src/pages/         Pipeline, Chats, Broadcast, Connect, Settings, Receipts
```

Тест базы: `go test ./internal/store/`
